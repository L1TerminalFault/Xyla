# Xyla

hey everyone, so xyla is a video editor me and my freind have been building it mainly has a few goals: 
 - performance : its built with hardware acceleration as first class
 - reliablity : being as bug free and as crash free as possible
 - nice ui: we are not expertes in design but aimed at something better than the current state in the opensource editors ui.
 - feature fullness: not to mean to have too many features its more about when we write a certain tool into xyla we will write it in a way where everything you expect will be added and polished on instead of rushing things

xyla is aimed to be a similar NLE to other NLE's like kdenlive or olive and has some similar set of feature aims like node based compositing setups but is designed in a way where you are not a fan of nodes it would hide that away over ui for you.

you have to note that its early for xyla in many aspects and we are currently in active early stages of developement 

# contributing
since this is an early stage of things many things will changed and be upgraded and because of that we advice that you contact us and get assigned with something you can help with instead of deciding yourself. so that you do not collide with someone else in the team working on the same thing
